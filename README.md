# 🌍 World Happiness Report 2025 Analysis

## 📌 Project Overview

This project analyzes the **World Happiness Report 2025** dataset using **Python, NumPy, Pandas, and Matplotlib** to understand the factors that contribute to happiness across different countries.

The analysis follows a complete data analysis workflow, including data cleaning, exploratory data analysis (EDA), visualization, correlation analysis, and interpretation of results.

Through this project, I explored questions like:

- Which countries are the happiest?
- Which countries rank the lowest in happiness?
- Which factors contribute the most to happiness?
- Does higher GDP always result in greater happiness?

---

## 📊 Dataset

**Dataset:** World Happiness Report 2025

**Rows:** 147 Countries

**Columns:** 11 Features

### Features Used

- Country
- Happiness Score
- GDP
- Social Support
- Life Expectancy
- Freedom
- Generosity
- Corruption
- Dystopia
- Upper Confidence Interval
- Lower Confidence Interval

# 🔍 Key Findings

- Social Support has the strongest positive relationship with Happiness Score.
- GDP and Life Expectancy are also strongly associated with happier countries.
- Freedom contributes positively to happiness.
- Generosity shows the weakest direct relationship with Happiness Score.
- Countries with higher GDP generally tend to be happier, although wealth alone does not fully explain happiness.
- Happiness is influenced by multiple economic, social, and health-related factors working together.

---

# 💡 Conclusion

This project demonstrates how data analysis can be used to uncover meaningful insights from real-world datasets.

The findings suggest that while economic prosperity contributes to happiness, factors such as strong social support, better health, and personal freedom play equally important roles. Overall, happiness cannot be explained by a single factor, but rather by the combined effect of several aspects of quality of life.
